# 对照参考实现

参考：[FeatherHunter/dsh-mattpocock-skills-deck](https://github.com/FeatherHunter/dsh-mattpocock-skills-deck)（对照时取 `1.9.0-beta.34`）。

本插件是**适配 tern 的改良版**，不是逐像素移植。本文档回答两件事：哪些形态对得上，哪些是为了落在 tern 能力边界内而做的改造或退化。

## 参考实现的功能全貌

| 区块 | 内容 |
| --- | --- |
| BOARD 任务板 | 探索地图 / 实施地图 / 普通 ISSUE 三类并列表；每行带一键注入 prompt |
| 地图详情 | 像素风卡片墙，分「可接」「已结案」 |
| 单票详情 | 描述、验收标准、进度、评论 |
| STATUSBAR 胶囊 | 可接任务数、故障、需要诊断分流、刷新、ISSUE 处理路径表 |
| DEMAND 新增需求 | 引导用户在「探索流程」和「实施流程」中二选一，把 IDEA 落地 |
| SKILLS 技能面板 | 内置 27 个技能；可注入对话框，可看原文详情 |
| BACKENDS 多后端 | GitHub / 本地 Markdown / GitLab 切换，环境逐项自检 |
| VERSION 版本管理 | fetch / pull / push / add / commit、提交历史、worktree |
| APPEARANCE 外观 | 调色板 |
| setup 初始化 | 六步向导、GLOSSARY 布局（single / multi-context） |
| `truth.*` | 数据新鲜度、GraphQL / REST 配额预算、快照重建、降级标记 |
| `list.*` | 历史票分页、翻页位置失效、早期页内存裁剪 |
| `chainView` | 每个会话正在处理哪些票 |
| `deck-pr-list` | PR 列表 |
| triage 分流 | `needs-triage` 票的「诊断」动作 |
| 票动作模板 | `config/prompts/ticket-action-templates.yaml`，带 `{{shared:*}}` 公共小节，中英双语 |

## 逐项对照

### 对得上

| 能力 | 参考实现 | 本插件 |
| --- | --- | --- |
| 任务板列表 | 票按状态归位 | 四组：可领 / 已认领 / 被阻塞 / 已关闭 |
| 一键注入 prompt | 列表行按钮 | 票详情动作按钮 + 技能视图「注入技能」 |
| 地图详情 | 独立视图 | 独立视图：子票 / 迷雾 / 范围外 |
| 单票详情 | 独立视图 | 独立视图 |
| 技能面板 | 列表 + 详情 | 列表（按泳道分卡）+ 原文详情 |
| 技能可注入对话框 | 是 | 注入一行 `/技能名` |
| 胶囊状态栏 | 有 | 技能组版本，点击打开面板（口径见 `docs/spec/v1.md` §8） |
| 数据失败不清空 | 快照 + 降级标记 | issue 缓存兜底，提示「显示上次拉到的数据」 |
| 历史票分页 | 滚动分页 + 失效处理 + 内存裁剪 | open 全量 + 已关按需「加载更多」（口径见 `docs/spec/v1.md` §7） |

### 简化或退化

| 能力 | 参考实现 | 本插件 | 原因 |
| --- | --- | --- | --- |
| 地图分类 | 探索地图 / 实施地图分开 | 统一「地图」卡 | v1 未区分两种地图语义 |
| 地图详情呈现 | 像素风卡片墙 | 列表 + 卡片 | `tern.ui` 无自由布局能力 |
| 票详情字段 | 描述 / 验收 / 进度 / 评论 | 只有正文 | 评论与验收要多轮 gh 请求，v1 未取 |
| 票动作模板 | 每类多套，含 `{{shared:*}}` 公共小节，中英双语 | 每类一条短模板，中文单语 | 模板体积和语言维度都砍了 |
| 配额预算显示 | GraphQL / REST 剩余额度常驻 | 无 | 只做了失败退缓存，没做额度展示 |
| 会话关联 | `chainView` 显示每个会话在办哪些票 | 无 | 需要读宿主的会话记录，tern 侧没有对等接口 |
| 后端降级 | REST / GraphQL 双通道自动切换 | 单通道 + 缓存 | v1 单后端 |

### 范围外（已决策不做）

| 能力 | 决策依据 |
| --- | --- |
| 内置 / 打包技能 | 技能必须外置，运行时只读消费用户安装的那份 |
| 新增需求流程（DEMAND） | v1 只做浏览与注入，不引导建票 |
| 多后端（GitLab / 本地 Markdown） | v1 只 GitHub via `gh` |
| 环境自检 | 同上，v1 不做 |
| 版本管理页 | 面板不做 git 操作 |
| 外观调色板 | 不做主题系统 |
| 六步初始化向导 | tern 侧首次配置更轻 |
| PR 列表 | 面板只围绕 issue 与技能 |
| triage 标签分流 | 动作按 wayfinder 票类型分，不按 triage 标签（不同轴） |
| 写票（认领 / 关闭 / 打标签） | v1 只读，留 v2 |

## 因 tern 能力边界所做的改造

这些不是「没做」，是为了能跑在 tern 上必须换的实现方式。

| 项 | 参考实现 | 本插件 | 约束 |
| --- | --- | --- | --- |
| 宿主形态 | Electron 侧边栏 + 独立页面 | 单个 panel block | tern 插件只有 block，没有多页面容器 |
| 多视图组织 | 侧边栏多页切换 | 单块 + 顶部按钮切换四态 | `tern.ui` 无标签页原语 |
| 技能来源 | 插件内置 | 探测用户已装的技能包，只读 | 不打包任何 skill 正文 |
| 注入通道 | 直接调宿主 API | 宿主写 kv → 窗口轮询 → `cx.agents:ask`，无邻近 agent 退剪贴板 | `cx.agents:ask` 只在窗口半边可用 |
| 数据拉取 | 主进程内 fetch | 宿主半边起 `gh` 子进程 | 宿主半边 `tern.process.run` 可用；窗口半边有 500ms 墙钟预算 |
| 标签识别 | 固定 `wayfinder:*` | 任意前缀 `*:<种类>`，裸标签不认 | 让用户能换自己的命名空间；裸标签不认是防误判 |
| 键盘操作 | 完整快捷键 | 以鼠标为主，交互全部有鼠标入口 | 宿主 block 的 key 事件送达不稳定，不能只靠键盘 |

## 本插件多出来的

参考实现没有、本插件自己加的：

| 能力 | 说明 |
| --- | --- |
| Spec 卡 | 把 `ready-for-agent` 的顶层 issue 单列一卡，显示「N 工单 · M 未完成」，点开看详情 |
| 按创建时间排序 | 默认最新在上，一键切最早在上，缺时间的票沉底 |
| 票类型图标 | grilling / prototype / research / task 各一个行首图标 |
| 技能按泳道分卡 | 泳道来自技能包自身的阶段链，不自造分类 |

## 已知的功能缺口

按影响排序，都还没做：

1. **票详情的验收标准与评论** —— 参考实现能在一个视图里看全，这里只看得到正文。
2. **写票** —— 认领、关闭、改标签都要跳浏览器。
3. **配额展示** —— 限流时只有「显示上次拉到的数据」，看不出还剩多少额度。
