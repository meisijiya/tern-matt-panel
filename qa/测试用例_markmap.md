# Tern Matt 面板 v1 测试用例

> **测准声明**：本文件以 `D:/26code/tern-matt-panel` 分支 `main`（基线 commit `7447c56`）实际实现为唯一功能基线；需求/设计文档降为背景对照（偏离见附录 D）。代码级证据（文件位置、缺陷记录、接口对照）统一放文件末尾附录，**不写进用例正文**。

<!-- 导读区四件套 -->

> **功能简介**：Tern Matt 面板是一个终端面板插件，把外置安装的中文 mattpocock 技能包做成游戏化可视面板 —— 左侧浏览技能（按包原生阶段链分泳道），右侧浏览本仓库的 wayfinder 任务板（地图与前沿票），并把「一行斜杠技能名」注入到旁边的编码 agent。
>
> **角色**：面板操作者 → 浏览技能、浏览任务板、选票、注入技能或票动作；邻近编码 agent → 接收面板注入的提示词；技能包上游 → 提供技能正文与包版本号（插件只读消费，不复制）。

**环境与账号**：

| 项 | 值 |
|----|----|
| 被测入口 | tern 0.9.11 GUI，命令面板输入 `Matt 面板` 打开面板块 |
| 插件安装位置 | `D:/26code/tern-matt-panel`（开发态用 `tern plugin link` 挂载） |
| 技能包安装位置 | 本机已装中文技能包 `devcxl/mattpocock-skills-zh`（默认探测 omp 插件缓存的 marketplaces 目录） |
| 任务板数据源 | 本仓库 `meisijiya/tern-matt-panel` 的 GitHub issue，需 `gh` CLI 已登录（账号 meisijiya，2.95.0） |
| 注入目标 agent | 需在 tern 窗口旁存在活的 omp agent 块；**测试环境当前无活 agent**，注入走剪贴板退路 |
| 自动化入口 | `bash test/all.sh`（单元 + 真机 e2e 一把跑） |

**术语表**：

| 术语 | 中文名 | 说明 |
|------|--------|------|
| 泳道 | 阶段分组 | 技能按包自带的阶段链分为入口 / 规划 / 实施 / 审查与交付 / 旁路与专项五组 |
| 地图 | wayfinder 路线图 | 一张带路线图标签的 issue，标题含「地图」，内含若干子票 |
| 前沿 | 可领的票 | 未关闭、未被认领、且没有被未关闭票阻塞的票集合 |
| 迷雾 | 尚未明确 | 地图正文里「尚未明确」一节的文字，只呈现不解析 |
| 范围外 | 明确不做的事 | 地图正文里「范围外」一节的文字，只呈现不解析 |
| 注入 | 投递提示词 | 把一行斜杠技能名投给邻近 agent；无 agent 时复制到剪贴板 |
| 回写 | 结果通道 | 窗口侧执行完注入后把结果写回共享存储，宿主据此改写提示文字 |
| 提交中 | 等待回写的中间态 | 宿主发出注入请求后、收到回写前的提示文字 |

**图例**：P0 = 冒烟（失败则核心不可用）/ P1 = 常规（默认级别，未标注即 P1）/ P2 = 边界与低频；`TC-{模块号}-{序号}` = 用例唯一编号；`（SMOKE-{序号}）` = 冒烟用例序号；`[并发]` / `[可靠]` / `[集成]` = 类型域轴标签（来自测试策略）。

> 标准测试数据：任务板固定使用本仓库 `meisijiya/tern-matt-panel` 的 issue 集合（地图 1 张：#1「Tern Matt 面板（MattSkillsDeck for Tern）」，含 9 张子票）；技能包默认可见 31 个技能、5 条泳道。

## 4. 注入链路

> 前置：面板已打开；技能或票已选中。

### 4.1 主流程

- **TC-04-01 技能注入提交后提示进入等待回写状态** [P0]（SMOKE-8）
  - 前置条件: 无额外前置
  - 操作步骤: 1. 打开面板（技能视图） 2. 选中任一技能 3. 点击顶部「注入技能」按钮
  - 预期结果: 提示文字先显示「提交中」，不直接显示「已提交」

- **TC-04-02 注入成功后提示改为已提交** [P0]
  - 前置条件: 窗口旁存在活的 omp agent 块
  - 操作步骤: 1. 打开面板 2. 选中一个技能 3. 点击「注入技能」按钮 4. 等待 10 秒
  - 预期结果: 提示文字从「提交中」变为「已提交」并带出技能名；该 agent 收到一行以斜杠开头的技能调用

- **TC-04-03 注入失败时提示改为提交失败并带原因** [P0] [可靠]
  - 前置条件: 窗口旁无活 agent 块，或 agent 正忙
  - 操作步骤: 1. 打开面板 2. 选中一个技能 3. 点击「注入技能」按钮 4. 等待 20 秒
  - 预期结果: 提示文字从「提交中」变为「提交失败」并带出原因；技能正文已复制到剪贴板

- **TC-04-04 注入内容只是一行斜杠技能名** [P0]
  - 前置条件: 已选中 ask-matt 技能
  - 操作步骤: 1. 点击「注入技能」按钮 2. 从剪贴板读出注入内容（无 agent 时退到剪贴板）
  - 预期结果: 内容为一行斜杠加技能名，不含该技能正文

- **TC-04-05 票动作注入使用票专用模板** [P1]
  - 前置条件: 已打开一张带类型标签的票
  - 操作步骤: 1. 点击该票的类型动作按钮 2. 从剪贴板读出注入内容（无 agent 时退到剪贴板）
  - 预期结果: 内容含该票的标题与链接，并给出对应的斜杠技能调用；不是裸的技能名

- **TC-04-06 注入请求的序号不回退导致请求被丢弃** [P1] [并发]
  - 前置条件: 无额外前置
  - 操作步骤: 1. 连续点击「注入技能」按钮三次，每次间隔 1 秒 2. 观察每次点击后的提示变化
  - 预期结果: 三次请求各自被窗口侧接收并处理（每次提示都从「提交中」变为一个结果），没有哪一次停在「提交中」不动

- **TC-04-07 面板与另一窗口同时发请求时请求不串窗口** [P2] [并发]
