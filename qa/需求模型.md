## 1. goal（需求目标）

把**外置安装**的中文 mattpocock 技能包（`devcxl/mattpocock-skills-zh`）做成一个游戏化的可视面板，并承载 wayfinder 的地图/前沿语义，让用户在终端里**看技能原文 → 一键把指令送进旁边的 agent → 看当前可领的票**。

成功标准（spec §9 的十条验收，E1；下文 §3–§9 按代码逐条落到证据）：

1. `tern plugin list` 末尾是 `ready`；
2. 面板列出技能包技能、按泳道分组、显示技能组版本；
3. 技能详情显示 `SKILL.md` 原文；
4. 任务板列出 `wayfinder:map` 地图与子票，算出前沿，显示阻塞关系与迷雾/范围外两节文字；
5. 技能「注入」把 `/技能名` 送进邻近 agent（无 agent 时复制到剪贴板并提示）；
6. 票的动作把模板渲染结果送进邻近 agent；
7. 状态栏胶囊显示前沿票数与技能组版本，点击打开面板；
8. 探测不到技能包时技能区显示安装提示，任务板仍可用；
9. 插件目录与插件数据目录**不含任何 skill 正文副本**；
10. `test/build.sh` 全绿。

> ⚠ 第 4 条与第 5 条与当前代码**不一致**，见 §10 附录 A（规格 vs 代码不一致清单）。

- 插件打包 / 同步 / 镜像任何 skill 正文。**证据**：E1 spec §2/§6；E2 `lib/skills.luau:3-4`、`:64`（只读不复制）；E4 `grep` 全库无 skill 正文常量。
- 代装 / 代下载 / 代升级技能包。**证据**：E1 spec §2；E2 `host.luau:310-313`（只提示不代装）。
- DSH 的版本管理页、外观调色板、六步初始化向导、新增需求流程、多后端切换。**证据**：E1 spec §2、issue #1 票 #2。

### 2.3 非目标带来的验收约束

- **没有 API 层可测**：`gh` 子进程是唯一的外部 IO 面（`host.luau:190`）。
- **没有数据库**：`tern.kv` 是 JSON 文件型全局存储，不是查询面（`tern.d.luau:2076-2085`）。
- **视觉回归不可测**：样式交给主题，插件只排版（`styles.css`、`spec §3`）。

## 3. roles（角色 × 能做 / 不能做）

### R1 终端用户（面板操作者）

能做（E2，键位与按钮全在 `host.luau`）：
- 切换三视图（`host.luau:827-836` 顶部按钮 / `:613-621` `Tab`）；
- 浏览技能列表、移动选中、看 `SKILL.md` 原文（`:650-689`、`:795-802`）；
- 切换隐藏分类显示 `in-progress` / `deprecated`（`:641-646`、`:847-851`）；
- 浏览地图列表与前沿票列表、打开票详情（`:710-736`、`:803-819`）；
- 复制技能名 / 票信息、浏览器打开票链接（`:698-706`、`:737-753`、`:859-874`）；
- 请求注入（技能 `i` 键 `:690-697`；票详情动作按钮 `:876-883`）；
- 手动刷新、换仓库（`:631-640`、`:837-846`）；
- 手动指定任务板仓库（`:262-270` → `window.luau:199-214` 的 `cx:prompt`）。

不能做：
- 安装 / 升级技能包（**硬约束**，E1 spec §2/§5；E2 `host.luau:310-313`）；
- 在面板里写票（认领 / 关闭）—— v2（E1 spec §2）；
- 在面板里改 lane 映射表 —— 映射表是插件源码（`lib/lanes.luau:19-25`），用户无编辑入口（E2 全库无写 `lanes` 的路径）。

### R2 邻近 agent（omp agent 块，window 半边可见）

能做：
- 接收注入文本（`cx.agents:ask`，E2 `window.luau:134-136`）；
- 处于 `idle` / `working` / `waiting_input` / `exited` 状态之一（E1/E3 `tern.d.luau:762`）；
- 报告投递失败原因（`delivery_error`，E3 `tern.d.luau:763-764`）。

不能做：
- 面板不读 agent 的对话内容，也不依赖 agent 状态做面板逻辑（E2 窗口半边只用 `agent.pane` / `agent.state` / `agent.delivery_error`）。

### R3 插件本身

能做：只读探测技能包目录、只读拉 `gh` issue JSON、渲染 `tern.ui` 树、写 `tern.kv`、请求窗口半边注入、弹 toast、复制剪贴板、开链接。

不能做（硬约束）：
- 不打包 / 不复制 / 不镜像 skill 正文（E1 spec §6；E2 `lib/skills.luau:3-4`）；
- 不内嵌 skill 正文到模板（E2 `lib/templates.luau:2-3`；E3 单测 `test/run_tests.luau:410-411`）；
- 不写 GitHub（E2 无写调用）；
- 不代装技能包（E2 `host.luau:310-313`）；
- 不在宿主半边做注入（`cx.agents:ask` 是 window-only，E1 `docs/research/host-half-runtime.md:81`；E3 `tern.d.luau:772,781`）。

### R4 技能包上游（外部供给方，非插件内角色）

技能组是外置的单一真源，随上游走；插件不锁版本、不维护副本（E1 spec §2/§6、README:13；E2 `lib/paths.luau:19-42` 只做发现）。上游增删技能会直接改变面板可见内容与泳道归属。
